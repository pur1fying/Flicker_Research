# Event Flicker Removal


提供荧光照明下的事件频闪数据及梳状滤波实现，有公开 Drive 入口；仓库注明 academic use only。数据是异步事件流，适合研究调制时间结构或测量系统，不能直接当成普通 RGB 干净/频闪帧对。

来源：[官方仓库](https://github.com/ziweiWWANG/EFR)、[论文](https://arxiv.org/abs/2205.08090)。
