# Canon：高频防闪与检测边界

具体机型的检测范围、推荐曝光与多光源/运动限制，不能推广为所有 Canon 相机。

## 已核对的条件

EOS R6 Mark III 本页给出 50.0–2011.2 Hz 检测范围和 1/50.0–1/8192.0 秒设置范围。重复纹理、运动、多灯、极亮/极暗和很小的发光体会影响检测。

## 对数据集的意义

把重复织物纹理、运动物体、多灯和小光源列成负例/困难例；单独保存相机型号与模式。推荐快门与真实曝光积分真值分别记录。页面正文已读，未复现厂商检测算法。
