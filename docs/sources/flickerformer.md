# Flickerformer


使用 BurstDeflicker 进行多帧频闪恢复，并讨论周期性与方向性。**应计为方法论文，而不是重复计算成一个新数据集。** 它表明仅用通用图像质量分数不足以表达条带结构和多帧错位问题；本轮不展开网络架构。

来源：[论文](https://arxiv.org/abs/2603.22794)、[官方仓库](https://github.com/qulishen/Flickerformer)。
