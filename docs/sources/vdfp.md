# DeViD / VDFP


- 108 段内容：60 段取自已有视频数据、48 段另行收集，播放到 LED 显示矩阵后重拍。
- 处理空间、时间和颜色对齐；训练合成通过时空退化场构造条带。
- 正文说明硬件覆盖主要是 LED 矩阵。这里“多场景”主要指屏幕播放内容，不等于在多种实体房间灯光下拍摄人物。
