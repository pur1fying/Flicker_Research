# Infineon BCR601：纹波抑制与模拟调光

用特定参考电路说明 LED 也可以低纹波，不能把所有 LED 都模拟成方波。

## 阅读范围

精读应用笔记 Overview、技术参数、Current Stability 和调光相关部分，并查 LED drivers 门户。参考设计通过稳流与模拟调光改变输出，指标有明确负载和输入条件。

## 数据条件

加入稳定/低调制 LED 对照；记录驱动板、负载、调光水平和供电纹波。不能将单块参考板的结果推广到同类所有灯。
