# Fujifilm X-H2：两类防闪设置

首帧择时、每帧择时和精细快门是不同操作，必须保存拍摄模式。

## 阅读范围

已读 SHOOTING SETTING 的 SHUTTER TYPE、FLICKER REDUCTION、FLICKERLESS S.S. SETTING。

前一功能分 ALL FRAMES / FIRST FRAME / OFF，并注明电子快门时关闭、视频不适用；另一个设置允许微调快门减少 LED 频闪。

## 对数据集的意义

连拍序列不能仅写“防闪已开”，还应记录是否每帧重新测量。这里是 X-H2 静态照片菜单，不据此推断用户实际相机参数。
