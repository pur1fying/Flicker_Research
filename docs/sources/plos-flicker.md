# SRGAN-PBAFT：数据机制疑点


论文使用 Middlebury/NYU2 等底图，并报告一个 300 图像的室内合成集合。但 §3.1 的实际文字描述是基于深度、散射系数和大气光的**雾图合成**，与灯具时间调制的频闪模型并不一致。因此本轮把它列为检索到但数据机制存在疑点的工作，**不将其作为可用的物理频闪数据依据**。页面的 Data Availability 声明也不等于提供独立原始频闪帧对。
