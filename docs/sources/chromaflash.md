# ChromaFlash：主动光谱编码

滚动快门可将主动改变的波长编码到图像行；这是主动测量相关工作。

## 阅读范围

核对 ACM DOI `10.1145/3678582` 的摘要和作者仓库，仓库 README 为 Work in progress。

## 使用边界

这项工作主动控制照明，不是消除未知被动环境频闪的数据集。可用于理解颜色与时间的耦合；不能因名称相关就扩展为本项目必须实现的硬件系统。
