# Nikon Z9：频率设定与整周期曝光

同一套功能可保存不同光源频率，不能把默认预设当成灯具频率分布。

## 阅读范围

已读 frequency setting mode 与注意事项；继续跟踪了关联的 [Video Flicker Reduction](https://onlinemanual.nikonimglib.com/z9/en/vrm_video_flicker_reduction_148.html)。

照片频率模式默认预设 7680/3840/2880/1920 Hz，支持 30–9999 Hz 输入。频率配置用于选择周期整数倍的曝光；官网仍要求检查实际照片。

## 数据解释

照片高频模式与视频 50/60 Hz 设置不合并成一个功能。用户界面的名义档位不视为已标定的曝光秒数；模拟器以明确时间戳积分。
