# BlazeBVD


沿用 DAVIS/MS-COCO 及 Blind Deflickering Dataset，训练退化包含按空间低分辨率生成并放大的变化场、持续若干帧的扰动。属于通用视频光度变化基线，**不是一个新的可标定灯具物理数据集**。

来源：[论文 §5.1](https://www.ecva.net/papers/eccv_2024/papers_ECCV/papers/02526.pdf)。
