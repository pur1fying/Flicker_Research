# MetTLM：波形与测量验证

标准数学波形用于核对算法，不能作为真实商品灯具的概率分布。

## 阅读范围

核对 Results 的 waveform set 1、公开报告与相关论文列表，读取最终报告相关摘要。

## 资源用途

数学波形集适合验证积分、TLM 指标和采样误差；DELIGHT 等实测资源用来约束灯具外观。两者保存不同的来源类型。
