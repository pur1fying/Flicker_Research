# Deegan 2022：相机频闪指标

用调制、可见性和拍频分开描述相机记录的闪烁。

## 阅读范围

已读指标定义和曝光/饱和相关讨论，包含 FMI、FDI、MMP 和 Flicker Beat Frequency。

## 对数据集的意义

除了重建误差，还记录发光体是否被采到、背景对比阈值、调制强度和观察序列长度。阈值依应用定义，不能把人眼 Pst/SVM 当相机指标。
