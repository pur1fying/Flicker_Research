# 真值、采样与覆盖

## 7. 干净真值的定义

建议主任务采用**保持平均照明的反事实真值**：

```text
输入：相同场景轨迹 + 原始灯具时间调制 + 原始逐行曝光
真值：相同场景轨迹 + 每个发光分量的周期平均输出 + 同一逐行曝光
```

每个波长/光谱基分量分别求平均。保留正常的亮度包络、色彩指令、物体运动和移动阴影。若主任务是稳定调光，不应把用户有意切换舞台灯颜色也标成要删除的退化。

必须保证：

1. 输入和 GT 使用同一相机轨迹、对象轨迹、曝光窗口、裁切与输出方向。
2. GT 不用相邻帧均值代替；那会混入运动模糊/重影。
3. GT 不删除闪烁灯，也不一律恢复到灯的峰值输出。
4. 主 GT 保留同样曝光积分的运动模糊和滚动快门几何。需要无模糊/全局快门目标时，另存辅助目标并另命名任务。
5. 首先保留无噪声输入与无噪声 GT，隔离光照问题；再生成噪声/ISP 版本。渲染随机数可用于降低 Monte Carlo 差分方差，传感器噪声则需独立定义，不能不加说明地强制复用同一噪声图。
6. 极暗、持续漏采、饱和位置保存信息缺失标签。GT 可以含输入不可观测的内容，但评估必须分层报告。

对于非周期或频率漂移灯具，GT 使用已知驱动指令对应的平均包络；需要写清平均操作的条件和时间尺度，避免把真实慢变化一同消除。

## 8. 合成精度的三个等级

### 等级 A：图像域扰动，只作对照

在已有干净图上施加全局或局部条带，可用于快速检查数据读取和覆盖趋势。不能证明场景光照、材质反射和曝光内动态正确。

### 等级 B：逐光源 RGB 光传输 + 显式曝光积分

对固定时刻的场景，以线性域获取各独立光源/光谱近似分量 A_k(p,t)。自定义时间积分：

```text
X(n,p) = Σ_j w(n,y,j) Σ_k A_k(p,t_j) q_k(t_j)
Y(n,p) = Σ_j w(n,y,j) Σ_k A_k(p,t_j)
```

w 对每一行表达曝光区间覆盖。如果输出的是平均线性亮度，权重和为 1；如果输出传感器辐射曝光量，权重和等于曝光秒数。两个量不能混用。

**快速近似**只渲染每帧参考时刻的 A_k，再乘解析行系数。它仅在整个读出和曝光期间几何/光传输变化足够小时成立。快速运动、高光闪过、遮挡显露需要子帧版本。

### 等级 C：光谱光传输 + 时间积分 + 标定相机

在等级 B 的时序上加入 S(λ,t)、材质光谱反射/透射、镜头与 QE。使用 Mitsuba 的光谱变体或 ISET/PBRT 路径，仍需自行组织动态场景、灯光时序、逐行曝光和标签。[Mitsuba 变体](https://mitsuba.readthedocs.io/en/latest/src/key_topics/variants.html)、[ISET-LFM](https://github.com/AyushJam/iset-lfm)

**建议：B 作为大规模主体，C 作为小而严格的光谱验证子集。** 若研究问题明确要求验证“同 CCT 不同 SPD × 不同材质 × 不同相机”，则 C 是必需部分，B 不能宣称完全满足该目标。

### 时间采样与成本

- 有限个随机时间点可能完全错过低占空比 PWM 脉冲。优先按已知开关时刻分段积分，或解析计算时间权重。
- 几何变化与灯光变化可以使用不同采样密度：在光传输变化慢的小区间内，准确积分 q(t)，而不是为每个高频脉冲重渲染整场景。
- 近似误差由运动位移、可见性变化、高光宽度与波形共同决定；用加密时间采样的结果检验收敛。
- 基础成本近似与“场景数 × 帧数 × 几何子帧数 × 每次渲染成本”有关；光源组可共享路径追踪过程，但增加输出通道和内存。重复单灯渲染时还要乘光源分量数。
- 光源独立变化时，缓存必须按独立组足够细地分解。一个“所有车灯”组不能任意拆出每盏车灯的新相位。

## 9. 建议的参数覆盖表

以下是**候选采样点和分层方案**。最终应根据目标相机模式与真实灯具测量收缩，不能把整张表直接做无约束笛卡尔积。

| 轴 | 建议起点 | 设计原则 |
|---|---|---|
| 视频帧率 | 24、25、30000/1001、30、50、60000/1001、60、120、240 | 保留有理数，不混淆慢动作播放 fps 与采集 fps |
| 曝光时长 | 0.1、0.25、0.5、1、2、4、8、10、16.67、20、40 ms 的适用子集 | 受帧率/硬件模式约束；额外密集覆盖整周期附近 |
| 首末行时间差 | 0、1、5、10、20、30 ms 的适用子集 | 0 作为全局快门对照；与传感器模式绑定 |
| 时间频率 | 电网相关 50/60/100/120 Hz；PWM 按对数取样约 100 Hz–20 kHz | 上限应由目标设备和测量决定；记录基频与谐波，不能一律标灯频 100 Hz |
| 调制深度 | 无、弱、中、强；正弦 a∈[0,1] | 使光强非负，兼顾近零信号和细微频闪 |
| PWM 占空比 | 如 0.05、0.1、0.25、0.5、0.75、0.9 | 区分恒峰值与恒均值；限制不合理峰值功率 |
| 相位 | 初相均匀覆盖；后续由真实时间推进 | 同驱动组共享参数；不同电网相位有相关结构 |
| 非理想性 | 频漂、抖动、有限边沿、低频包络 | 先独立消融再组合；避免每帧重抽波形 |
| 灯具/驱动组数 | 1、2、3、4、8，以及固定总照明对照 | 数量之外看有效贡献和独立驱动数量 |
| 稳定环境占比 | 从近 0 到主导照明分层 | 分母用明确定义的平均辐射/照度，避免单位混杂 |
| 光谱/颜色 | 标准灯谱 + 型号实测 + RGBW 通道 | 同色温不同光谱要有配对案例，颜色随时间变化另标 |
| 材质 | 漫反射、塑料、金属、镜面、玻璃、布料、皮肤、头发 | 每类都覆盖静止/运动与明暗区 |
| 动态 | 相机平移/旋转、刚体运动、人物关节/衣物、移动遮挡 | 强度用像素位移/曝光描述，不能只记 m/s |
| 传感器 | 多个 QE/噪声/满阱配置，固定与可变增益 | 未标定模型标为近似，不伪造相机型号真实性 |
| ISP/编码 | 线性、固定 ISP、独立 AE/AWB 干扰；无损主数据与压缩变体 | 相同底层场景保留版本关系 |
| 序列长度 | 短 1–2 s；中 4–8 s；慢拍频专组至少覆盖 2 个目标拍频周期 | 0.12 Hz 专组可取约 17–25 s；成本高，可先用静态几何缓存 |

## 10. 场景组合应像真实拍摄

| 场景族 | 组合示例 | 主要检查 |
|---|---|---|
| 室内窗边人像 | 稳定日光 + PWM LED 主灯，人物转身 | 前后景不同调制比，皮肤与衣物的显色 |
| 家庭/办公室 | 两类不同驱动 LED + 局部阴影 | 同类灯具也可有不同波形 |
| 超市/地铁 | 荧光/LED 灯阵列 + 金属/玻璃 | 同步组、反射、长走廊视角变化 |
| 棚拍 | 双色温灯或 RGBW 灯 + 柔光面 | 通道驱动时序和大面积光源软阴影 |
| 舞台 | 稳定背景 + 多色调光灯 + 正常灯光转场 | 去掉载波、保留有意的颜色/亮度节目变化 |
| 夜间街道 | LED/钠灯/金卤灯混合 + 湿地面 | 光源本体与反光，多光谱混合 |
| 汽车 | 脉冲车灯 + 路灯 + 相机运动 | 完全漏采、HDR 曝光差异、非均匀运动模糊 |
| 屏幕重拍 | LED 墙/LCD/OLED + 室内稳定灯 | 子像素/扫描/摩尔纹，独立子集 |
| 控制组 | 同样动作、纹理和镜面表面，但灯稳定 | 避免把织物条纹、正常高光/阴影当作频闪 |

不必首轮一次完成所有场景。建议先每族少量可解释案例，再用实测素材比较条带、颜色变化、动态边界和亮度分布，确认合成器的误差来自哪里。

## 11. 数据契约与拆分

每条序列至少保存：

| 组 | 必要字段/输出 |
|---|---|
| 来源与复现 | scene_id、trajectory_id、资产版本、灯具/驱动 ID、渲染器版本、代码提交、随机种子、许可证 |
| 时间 | 实际 fps 分子/分母、帧时间戳、行时间公式/表、曝光时间、采样权重、扫描方向 |
| 光源 | 数量、空间位置方向、发光面积、功率单位、SPD 或 RGB 近似、波形、相位组、平均/峰值策略 |
| 几何和材质 | 轨迹、材质参数、光谱数据引用、法线/粗糙度纹理、对象 ID |
| 相机 | 镜头/光圈、传感器尺寸、内外参、QE/CFA、满阱、噪声、增益、黑白电平、ISP |
| 主输出 | 频闪线性信号、稳定照明 GT、固定 ISP 版本；可选 RAW 与压缩版本 |
| 分解输出 | 每个独立光源/分量贡献、调制场或干净-输入差分、直接/间接光统计 |
| 可靠性 | 饱和/低信号/漏采掩码、参考时刻、曝光混合标记、几何标签的有效区域 |
| 近似级别 | 图像域 / 冻结几何 / 子帧 RGB / 光谱；光谱分辨率、时间采样密度、路径采样数 |

拆分必须在生成变体之前，按资产、场景布局、运动轨迹和灯具/驱动组进行。相同轨迹的相位变体或裁块不能跨 train/test。额外保留未见灯具、未见驱动、未见相机、未见材质和未见组合的 OOD 测试。

真实视频的开发集与最终测试集独立。素材用于校准后，就不应再作为“完全未见的真实泛化”证据。

## 12. 如何证明数据生成可信

1. **无调制恒等：**所有 q=1 时输入与 GT 一致至数值/采样误差。
2. **单灯解析对照：**静止平面正弦/PWM 与解析积分对比。
3. **完整周期：**静态周期信号完整周期曝光应消除相位差；半周期和非整周期作为反例。
4. **扫描控制：**τ=0 消除由逐行时间差形成的条带，但不要求帧间恒定。
5. **能量相加：**全灯线性渲染与逐灯贡献和一致；关闭非线性处理后检查。
6. **颜色对照：**固定 SPD、共同 q(t) 与分通道异相 q_j(t) 产生预期差别。
7. **材质对照：**灰卡、有色漫反射、金属、玻璃下测试不同灯的相对贡献。
8. **时间收敛：**加密子帧/开关事件积分后，误差持续减小；遮挡边缘单独报告。
9. **路径收敛：**提高光线采样，检查残余变化是不是渲染噪声或降噪闪烁。
10. **标签一致：**几何、光流、深度、分割的时间定义与图像一致，曝光混合边缘可标无效。
11. **真实测量比对：**固定灰卡/色卡和灯具，用光电测量或高速信号估计波形，比较静态及动态拍摄的行亮度图、相位推进、颜色与噪声。
12. **采样覆盖：**报告独立场景/灯具/轨迹数量、参数分布及有效退化强度；图像数量不是唯一多样性指标。

测量时保存仪器带宽、采样率、曝光/积分时长和误差；窄脉冲需要足够带宽。相机“防频闪”开关和 AE/AWB 会改变结果，应在标定中固定并记录。Pst/SVM 等人眼相关指标可以作灯具附加元数据，不能代替相机实际条带/漏采检查。

最终需要两种证据：**数值成像模型正确**，以及**模型能覆盖真实素材的主要现象**。第一种由解析/收敛测试支持，第二种必须有独立真实拍摄或测量支持。

索尼官方资料带来的增补：机械焦平面快门也可能是依次曝光；防闪烁择时与精细调节曝光时间是不同策略；记录文件和预览的闪烁表现可能不同。对应的参数和验证条件见 [索尼官方资料专题](/physics/sony)。
