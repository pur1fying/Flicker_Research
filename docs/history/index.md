## 第二轮新增与更正

- 系统记录 64 次关键词/厂商/引文查询，以及 Crossref、OpenAlex 的独立查询和访问限制。
- 前向引用发现 FlickerFix、DiffuFlicker；多灯方向补充 ICCP 2018、AC 本征分解与 NMF/ICA。
- 厂商记录扩展到相机、传感器、LED 驱动与测量机构；逐项保留实际阅读程度。
- 补充 AS1163 跨周期 dithering、CCFL 双时钟、GRR 曝光差异和静态光谱参考场景。
- ISET-LFM 的独立公式测试发现扩展参数域中的错误，已记录[具体调用与代码版本](/sources/iset-lfm)。未因此否定其默认示例或整个数据集。

## 网站验收结果

| 项目 | 已验证的结果 |
|---|---|
| 构建 | 本地、公开附件筛选、`/camera-research/` 子路径均成功 |
| 文档与资料 | 109 个页面，80 个独立资料记录；本地构建包含 20 份已校验 PDF |
| 链接与附件 | 检查三个构建中的内部路径、锚点、资产与公开附件范围，无错误 |
| 资料筛选 | 六种条件与关键词组合可定位 ISET；空结果和清除条件可用 |
| 中文全文搜索 | “逐行曝光”返回相关章节，回车跳转到正确锚点 |
| 自动新增 | 临时 Markdown 无需编辑索引，自动进入资料库和搜索；验收样本已删除 |
| 数学公式 | 三个核心显示公式在实际浏览器中渲染 |
| 原文 | ISET-LFM PDF 的正文和缩略页实际显示；独立打开/下载链接存在 |
| 移动端与主题 | 390 px 手机视口无页面横向溢出，目录能导航；明暗主题可切换 |
| 离线依赖 | 阻断外部 HTTPS 后，本地正文、公式及 PDF 仍可读取；PDF 请求为200 |
| 子路径运行 | 浏览器确认站点 base、导航和 PDF 均包含 `/camera-research/` |
| 元数据测试 | 新来源/反向引用通过；重复ID、缺失引用和非法附件路径会被拒绝 |

上述离线验收模拟的是互联网不可用但本机服务仍在运行，不承诺关闭服务后直接双击 HTML 文件阅读完整网站。公开构建只复制明确允许再分发的原文；当前只有已确认 CC BY 4.0 的高光谱 TLM 原文进入该构建。

## 运行与维护

新增/删除 Markdown 由本地启动器合并变更并重建页面清单与搜索索引；构建目录不参与热更新。预览根据构建类型选择正确输出目录。这些行为已在浏览器验证。

网站未公开部署；代码仓库已接入上方 GitHub 地址。当前仍不生成训练数据、不训练网络，也未运行 Blender/MATLAB 渲染链路。
