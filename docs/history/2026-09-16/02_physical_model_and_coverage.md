# 真实频闪数据集：成像模型、光源与场景覆盖

调研日期：2026-09-16。本篇中的参数范围、场景组合及测试阈值是**建议的实验设计**，不是某台相机或某类灯具的统一规格。文献事实与自行推导分别标明。

## 1. 三个需要分开的“频率/光谱”

| 名称 | 单位 | 描述 | 影响 |
|---|---|---|---|
| 光学光谱 SPD：S(λ) | 波长 nm；相对或绝对光谱功率 | 红、绿、蓝等波长上发出多少能量 | 光照颜色、材质显色、相机 RGB 响应 |
| 时间调制 q(t) 与其频谱 | Hz、占空比、谐波 | 灯随时间如何明暗变化 | 条带、漏采、帧间闪烁 |
| 相机采样 | fps、秒/行、秒/曝光 | 哪些时间段被哪些像素积分 | 把快变化映射为空间条带或慢拍频 |

**LED 与其他灯的光学光谱不同，不意味着必然产生不同的时间闪烁形态。** 一盏稳定驱动的 LED 可以很平稳；同一灯泡换驱动、调光档位或供电条件，时间波形可能明显变化。DOE 的 TLM 资料说明了驱动、调光、波形、深度与占空比的作用。[DOE 背景](https://www.energy.gov/cmei/ssl/flicker-research)

例如，两种灯若都满足 S(λ,t)=S₀(λ)q(t)，使用相同 q(t)，在静止、线性成像且只有该光源的条件下，其归一化明暗规律可以相同，只是颜色和亮度不同。若不同波长有不同的调制深度、延迟或驱动相位，则会出现颜色随时间变化；这时不能只用一个标量 q(t)。ACam 的分带灯具响应展示了这一区别。[ACam 正文 §2–3](https://www.cs.toronto.edu/~kyros/pubs/17.cvpr.acam.pdf)

**色温 CCT、显色指数 CRI、RGB 色值都不能唯一确定 SPD，也不能确定时间波形。** 要研究同色温不同灯照到不同材质上的差别，应保存光谱数据本身。

## 2. 从光源到像素的完整过程

### 2.1 光源与光传输

对每个发光单元 k，记录发射函数：

```text
E_k(λ, u, ω, t)
```

λ 是波长；u 是发光面位置；ω 是发射方向；t 是时间。它允许同一灯板不同分区、LED 屏不同像素分别变化。

普通灯具可先用可分离近似：

```text
E_k(λ,u,ω,t) = S_k(λ) × P_k(u,ω) × b_k(t) × q_k(t)
mean(q_k over a cycle) = 1
```

b_k 表示应保留的慢速亮度变化；q_k 表示要去掉的快速调制。多通道灯或荧光响应需要扩展为多个光谱基分量：Σ_j S_kj(λ)P_kj(u,ω)b_kj(t)q_kj(t)。

物体表面由反射/透射函数、法线、几何和遮挡共同把发射光变成相机接收的辐亮度 L(p,λ,t)。线性、无荧光的固定场景中，不同光源贡献可相加，且要包括间接反射：

```text
L(p,λ,t) = Σ_k L_k(p,λ,t)
```

这种线性叠加是逐光源缓存的依据；不能在 gamma、饱和、局部色调映射或独立降噪之后再假定它成立。[PBRT 光谱表示](https://pbr-book.org/4ed/Radiometry,_Spectra,_and_Color/Representing_Spectral_Distributions)、[Blender 线性颜色工作流](https://docs.blender.org/manual/en/4.3/render/color_management.html)

### 2.2 快门时间

第 n 帧传感器第 y 行的曝光起始时间，首版可设：

```text
t_start(n,y) = t0 + n/F + y × Δt_row
τ_readout = (H_sensor - 1) × Δt_row
t_end(n,y) = t_start(n,y) + T_exp(n,y)
```

- F 是真实帧率，如 30000/1001，而不是把它四舍五入为 30。
- Δt_row 是行延迟；τ_readout 是首末行曝光起点差，**不是曝光时长**。
- T_exp 是每行曝光时长，不等于 1/F。
- 全局快门对应所有行起点相同；它仍可能产生帧间 LED 闪烁。
- 滚动快门的扫描轴在传感器坐标内定义；显示旋转、电子防抖、裁切、缩放之后，方向可能改变。

不要简单规定“读出时间 + 曝光时间必须小于一帧周期”。不同帧和不同行的曝光窗口可能重叠；合法约束应来自具体传感器模式。首版选择一致的普通视频模式，特殊多曝光/交错读出另建配置。

### 2.3 光谱、光学与传感器

在一个简化的物理相机模型中，像素的期望电子数与下式成正比：

```text
μ_e(n,p,c) = ∫[row exposure] w(t) ∫[wavelength]
             L_sensor(p,λ,t) × QE_c(λ) × λ/(h c_light) dλ dt
```

L_sensor 应包含镜头透过率、光圈、像素面积、渐晕及成像几何等作用；QE 是量子效率。w(t) 表示快门权重，多次开关曝光可有多个窗口。

CFA 的滤色响应在光子积分阶段已经参与各像素的选谱。随后模拟光子噪声、暗电流/读出噪声、固定图样、满阱/电子饱和、增益与 ADC、黑电平，再进行 RAW 阵列组织、去马赛克、白平衡/颜色矩阵、色调映射、降噪锐化和视频压缩。具体顺序按目标传感器和 ISP 模式确定，不能把所有退化都当作最后一步添加的高斯噪声。[EMVA 1288 的相机响应定义](https://www.emva.org/standards-technology/emva-1288/emva-standard-1288-downloads-2/)

**Blender 的线性 RGB EXR 不是相机 RAW。** 从 sRGB 逆变换生成的 Bayer 数据也不能恢复已被裁剪的信息，或唯一恢复传感器光谱响应。

## 3. 快门、频率、相位：可校验的解析例子

对静止场景、单光源、矩形曝光和理想正弦：

```text
q(t) = 1 + a cos(2πft + φ)
q̄(n,y) = 1 + a sinc(fT) cos(2πf[t_start(n,y)+T/2] + φ)
sinc(z) = sin(πz)/(πz)
```

以下是该模型的数学推导，不是灯具实测：

| 条件 | 结果与意义 |
|---|---|
| f=100 Hz，T=1 ms | 调制幅度保留约 0.9836 倍，短曝光几乎保留全部波动 |
| f=100 Hz，T=10 ms | 恰好积分完整周期，理想静态模型中调制为零 |
| f=100 Hz，τ=15 ms | 首末行经历 1.5 个周期；条带密度由 f×行延迟决定 |
| f=100 Hz，F=30 fps | 固定行跨帧采样出现 10 Hz 混叠分量 |
| f=120 Hz，F=30 fps | 固定行每帧相位相同，可能留下不移动的空间条带 |
| f=120 Hz，F=30000/1001 fps | 拍频约 0.11988 Hz，周期约 8.3417 秒 |

![曝光和采样的解析例子](figures/shutter_sampling.png)

这说明：

1. 视频看起来“不闪”不代表不存在静态条带。
2. 较高灯频也可能被短曝光和行采样记录，不能单凭频率高就删掉该类样本。
3. PWM 含高次谐波，单一 f 的正弦模型不足；帧间相位应由连续时间推进，不能每帧独立随机。
4. 长曝光包含至少一个周期不等于完全无频闪；周期非整数时仍可能残留。曝光内运动也破坏静态下的精确抵消。
5. 同一观测可以对应多个真实频率。要保存真实生成参数，避免仅凭生成结果反推唯一灯频。

## 4. 光源类型怎样建模

以下是需要覆盖的机制类别。最终波形以灯泡、驱动、调光档位和测量记录为准，不用一条固定波形代表整类灯。[DOE 综述](https://www.energy.gov/cmei/ssl/articles/flicker-review-temporal-light-modulation-stimulus-responses-and-measures)、[DELIGHT 实测灯具表](https://webee.technion.ac.il/Sites/People/yoav/publications/supplement_ACam_docCVPR.pdf)

| 类型 | 光学特征 | 时间特征与应记录条件 | 数据集实现 |
|---|---|---|---|
| 日光/稳定环境光 | 连续光谱；随天空/时间变化 | 短窗口可近似稳定，云层等慢变化应保留 | 恒定分量或慢包络，对照样本 |
| 白炽/卤素 | 热辐射、偏暖、连续光谱 | 灯丝热惯性减弱并延迟电功率起伏；调光会改变温度与颜色 | 实测波形，或经标定的热响应近似；不直接套半波电流 |
| 荧光灯 + 磁镇流器 | 汞谱线 + 荧光粉宽带 | 常见与双倍电网频率关联的调制，存在相位和余辉 | 光谱基分量与实测时间响应 |
| 荧光/CFL + 电子镇流器 | 同类发光机制但驱动不同 | 高频驱动及可能残余低频包络 | 同时保留高频载波与低频分量，不只标“荧光灯” |
| 白光 LED + 稳定恒流 | 常见蓝光泵浦 + 荧光粉 | 可以低调制；具体由驱动和调光决定 | 低闪/无闪类别，避免模型学成“LED 必然强闪” |
| LED + 电源纹波/整流驱动 | 取决于芯片/荧光粉 | 可有 100/120 Hz 纹波、谐波、削顶或不对称 | 实测周期曲线与多个调光档位 |
| LED + PWM | 白光或单色、RGB/RGBW | 频率、占空比、上升下降沿、峰值、同步关系 | 显式脉冲积分；记录调光是恒峰值还是恒均值 |
| 双色温/RGB/RGBW 灯 | 多个不同光谱通道 | 通道可共频不同相位，也可异频、分时驱动 | 每个通道独立发射函数，整体标为一个灯具 |
| 金卤/高压钠/汞灯 | 谱线及宽带混合，显色与 LED 不同 | 放电和镇流器决定时间波形；热稳态条件重要 | 采用型号级实测响应，构成传统照明子集 |
| LED 显示墙 | 发光像素阵列 | 扫描行、复用、PWM、位平面、RGB 时序、内容相关占空比 | 单独屏幕发光模型；一个 AreaLight 不足 |
| LCD/OLED 屏幕 | 背光+液晶或自发光；可有偏振 | 刷新与调光机制依设备和亮度档位变化 | 表面内容坐标与相机扫描坐标同时建模 |

对每个灯具保存：发光技术、灯泡/驱动型号、驱动模式、供电、亮度档位、预热状态、平均光谱/颜色、波形、光输出单位、发光面尺寸、角分布、位置方向、同步组、来源及测量不确定度。

**额定电功率不等于光学辐射功率。** Blender 的点/聚光/面光 `energy` 映射到光功率，不能把“60 W 灯泡”直接填成 60。流明按人眼敏感度加权，同流明的不同 SPD 对相机也可能产生不同电子数。[Blender 灯功率说明](https://docs.blender.org/manual/en/4.3/render/lights/light_object.html)

## 5. 光源数量、分组与空间混合

至少区分三个数量：

- **灯具数量**：房间里有几盏灯。
- **发光分量数量**：一盏 RGBW 灯有几个通道/区域。
- **独立时间驱动组数量**：哪些分量共用相位、频率和波形。

三盏灯共用驱动，与三盏各自 PWM 的灯不同。来自同一电网或同一控制器的灯可能存在相位关联；不能把每盏灯、每帧都独立随机相位。

建议分层覆盖：单灯；单闪灯+稳定环境光；同频异相多灯；异频多灯；同色温不同驱动；不同色温/颜色多灯；一个主灯加若干弱灯。比较数量时控制总照明，另设亮度变化维度。

![两种颜色与频率的空间混合示例](figures/multilight_example.png)

该图是解析示意：不同位置接收不同灯的比例，因此各处的调制强度和颜色不同。真实三维贡献图应由光传输、材质与遮挡得到，不能用随机遮罩冒充物理生成。

## 6. 材质、反光与几何

| 因素 | 为什么影响频闪观测 | 必须保存/覆盖 |
|---|---|---|
| 漫反射/有色表面 | 对不同波长有不同反射比例；改变各通道信噪比 | 反照率或光谱反射率、纹理来源 |
| 金属 | 带色镜面反射，更强地选择特定灯方向 | 金属类型、粗糙度；严格模式需要复折射率/光谱数据 |
| 塑料/清漆/湿表面 | 漫反射与镜面光叠加，闪烁比例随视角变化 | 涂层、粗糙度、法线、灯尺寸 |
| 镜面 | 映出光源本体和周围照明，易出现强闪和饱和 | 反射射线路径、直接/间接源标签 |
| 玻璃/半透明 | 透射、反射、折射同时混合不同光源 | 厚度、IOR、吸收、反射/透射贡献 |
| 布料/丝绸 | 细纹理和各向异性高光可能与条带混淆 | 织物尺度、法线/位移、各向异性 |
| 皮肤 | 表面反射与次表面散射，多尺度颜色结构 | SSS、表面油光、肤色、几何细节 |
| 头发/毛发 | 细线结构、方向性高光和亚像素运动 | 毛发几何/材质、抗锯齿与遮挡 |
| 移动阴影 | 光源贡献随时间改变，不能统一按行相乘 | 物体/光源轨迹、遮挡与阴影边缘 |
| 荧光/磷光材料 | 会改变波长，可能带时间延迟 | 超出普通 RGB PBR 范围；单独定义或首版排除 |

在静止的线性、无荧光材料上，材质主要改变各光源/波长的权重，**不会凭空产生新的电驱动频率**。运动高光和阴影会产生新的观测时间变化，应保留在干净真值中。

普通照片贴图可能已经包含阴影和高光；将其当纯反照率再照明会产生双重光照。扫描资产要检查材质分解。可用 [MERL](https://www.merl.com/research/downloads/BRDF/) 的方向反射和 [RGL](https://rgl.epfl.ch/materials) 的光谱材质作标定小场景，PBR 资产主要用于外观多样性。

## 7. 干净真值的定义

建议主任务采用**保持平均照明的反事实真值**：

```text
输入：相同场景轨迹 + 原始灯具时间调制 + 原始逐行曝光
真值：相同场景轨迹 + 每个发光分量的周期平均输出 + 同一逐行曝光
```

每个波长/光谱基分量分别求平均。保留正常的亮度包络、色彩指令、物体运动和移动阴影。若主任务是稳定调光，不应把用户有意切换舞台灯颜色也标成要删除的退化。

必须保证：

1. 输入和 GT 使用同一相机轨迹、对象轨迹、曝光窗口、裁切与输出方向。
2. GT 不用相邻帧均值代替；那会混入运动模糊/重影。
3. GT 不删除闪烁灯，也不一律恢复到灯的峰值输出。
4. 主 GT 保留同样曝光积分的运动模糊和滚动快门几何。需要无模糊/全局快门目标时，另存辅助目标并另命名任务。
5. 首先保留无噪声输入与无噪声 GT，隔离光照问题；再生成噪声/ISP 版本。渲染随机数可用于降低 Monte Carlo 差分方差，传感器噪声则需独立定义，不能不加说明地强制复用同一噪声图。
6. 极暗、持续漏采、饱和位置保存信息缺失标签。GT 可以含输入不可观测的内容，但评估必须分层报告。

对于非周期或频率漂移灯具，GT 使用已知驱动指令对应的平均包络；需要写清平均操作的条件和时间尺度，避免把真实慢变化一同消除。

## 8. 合成精度的三个等级

### 等级 A：图像域扰动，只作对照

在已有干净图上施加全局或局部条带，可用于快速检查数据读取和覆盖趋势。不能证明场景光照、材质反射和曝光内动态正确。

### 等级 B：逐光源 RGB 光传输 + 显式曝光积分

对固定时刻的场景，以线性域获取各独立光源/光谱近似分量 A_k(p,t)。自定义时间积分：

```text
X(n,p) = Σ_j w(n,y,j) Σ_k A_k(p,t_j) q_k(t_j)
Y(n,p) = Σ_j w(n,y,j) Σ_k A_k(p,t_j)
```

w 对每一行表达曝光区间覆盖。如果输出的是平均线性亮度，权重和为 1；如果输出传感器辐射曝光量，权重和等于曝光秒数。两个量不能混用。

**快速近似**只渲染每帧参考时刻的 A_k，再乘解析行系数。它仅在整个读出和曝光期间几何/光传输变化足够小时成立。快速运动、高光闪过、遮挡显露需要子帧版本。

### 等级 C：光谱光传输 + 时间积分 + 标定相机

在等级 B 的时序上加入 S(λ,t)、材质光谱反射/透射、镜头与 QE。使用 Mitsuba 的光谱变体或 ISET/PBRT 路径，仍需自行组织动态场景、灯光时序、逐行曝光和标签。[Mitsuba 变体](https://mitsuba.readthedocs.io/en/latest/src/key_topics/variants.html)、[ISET-LFM](https://github.com/AyushJam/iset-lfm)

**建议：B 作为大规模主体，C 作为小而严格的光谱验证子集。** 若研究问题明确要求验证“同 CCT 不同 SPD × 不同材质 × 不同相机”，则 C 是必需部分，B 不能宣称完全满足该目标。

### 时间采样与成本

- 有限个随机时间点可能完全错过低占空比 PWM 脉冲。优先按已知开关时刻分段积分，或解析计算时间权重。
- 几何变化与灯光变化可以使用不同采样密度：在光传输变化慢的小区间内，准确积分 q(t)，而不是为每个高频脉冲重渲染整场景。
- 近似误差由运动位移、可见性变化、高光宽度与波形共同决定；用加密时间采样的结果检验收敛。
- 基础成本近似与“场景数 × 帧数 × 几何子帧数 × 每次渲染成本”有关；光源组可共享路径追踪过程，但增加输出通道和内存。重复单灯渲染时还要乘光源分量数。
- 光源独立变化时，缓存必须按独立组足够细地分解。一个“所有车灯”组不能任意拆出每盏车灯的新相位。

## 9. 建议的参数覆盖表

以下是**候选采样点和分层方案**。最终应根据目标相机模式与真实灯具测量收缩，不能把整张表直接做无约束笛卡尔积。

| 轴 | 建议起点 | 设计原则 |
|---|---|---|
| 视频帧率 | 24、25、30000/1001、30、50、60000/1001、60、120、240 | 保留有理数，不混淆慢动作播放 fps 与采集 fps |
| 曝光时长 | 0.1、0.25、0.5、1、2、4、8、10、16.67、20、40 ms 的适用子集 | 受帧率/硬件模式约束；额外密集覆盖整周期附近 |
| 首末行时间差 | 0、1、5、10、20、30 ms 的适用子集 | 0 作为全局快门对照；与传感器模式绑定 |
| 时间频率 | 电网相关 50/60/100/120 Hz；PWM 按对数取样约 100 Hz–20 kHz | 上限应由目标设备和测量决定；记录基频与谐波，不能一律标灯频 100 Hz |
| 调制深度 | 无、弱、中、强；正弦 a∈[0,1] | 使光强非负，兼顾近零信号和细微频闪 |
| PWM 占空比 | 如 0.05、0.1、0.25、0.5、0.75、0.9 | 区分恒峰值与恒均值；限制不合理峰值功率 |
| 相位 | 初相均匀覆盖；后续由真实时间推进 | 同驱动组共享参数；不同电网相位有相关结构 |
| 非理想性 | 频漂、抖动、有限边沿、低频包络 | 先独立消融再组合；避免每帧重抽波形 |
| 灯具/驱动组数 | 1、2、3、4、8，以及固定总照明对照 | 数量之外看有效贡献和独立驱动数量 |
| 稳定环境占比 | 从近 0 到主导照明分层 | 分母用明确定义的平均辐射/照度，避免单位混杂 |
| 光谱/颜色 | 标准灯谱 + 型号实测 + RGBW 通道 | 同色温不同光谱要有配对案例，颜色随时间变化另标 |
| 材质 | 漫反射、塑料、金属、镜面、玻璃、布料、皮肤、头发 | 每类都覆盖静止/运动与明暗区 |
| 动态 | 相机平移/旋转、刚体运动、人物关节/衣物、移动遮挡 | 强度用像素位移/曝光描述，不能只记 m/s |
| 传感器 | 多个 QE/噪声/满阱配置，固定与可变增益 | 未标定模型标为近似，不伪造相机型号真实性 |
| ISP/编码 | 线性、固定 ISP、独立 AE/AWB 干扰；无损主数据与压缩变体 | 相同底层场景保留版本关系 |
| 序列长度 | 短 1–2 s；中 4–8 s；慢拍频专组至少覆盖 2 个目标拍频周期 | 0.12 Hz 专组可取约 17–25 s；成本高，可先用静态几何缓存 |

## 10. 场景组合应像真实拍摄

| 场景族 | 组合示例 | 主要检查 |
|---|---|---|
| 室内窗边人像 | 稳定日光 + PWM LED 主灯，人物转身 | 前后景不同调制比，皮肤与衣物的显色 |
| 家庭/办公室 | 两类不同驱动 LED + 局部阴影 | 同类灯具也可有不同波形 |
| 超市/地铁 | 荧光/LED 灯阵列 + 金属/玻璃 | 同步组、反射、长走廊视角变化 |
| 棚拍 | 双色温灯或 RGBW 灯 + 柔光面 | 通道驱动时序和大面积光源软阴影 |
| 舞台 | 稳定背景 + 多色调光灯 + 正常灯光转场 | 去掉载波、保留有意的颜色/亮度节目变化 |
| 夜间街道 | LED/钠灯/金卤灯混合 + 湿地面 | 光源本体与反光，多光谱混合 |
| 汽车 | 脉冲车灯 + 路灯 + 相机运动 | 完全漏采、HDR 曝光差异、非均匀运动模糊 |
| 屏幕重拍 | LED 墙/LCD/OLED + 室内稳定灯 | 子像素/扫描/摩尔纹，独立子集 |
| 控制组 | 同样动作、纹理和镜面表面，但灯稳定 | 避免把织物条纹、正常高光/阴影当作频闪 |

不必首轮一次完成所有场景。建议先每族少量可解释案例，再用实测素材比较条带、颜色变化、动态边界和亮度分布，确认合成器的误差来自哪里。

## 11. 数据契约与拆分

每条序列至少保存：

| 组 | 必要字段/输出 |
|---|---|
| 来源与复现 | scene_id、trajectory_id、资产版本、灯具/驱动 ID、渲染器版本、代码提交、随机种子、许可证 |
| 时间 | 实际 fps 分子/分母、帧时间戳、行时间公式/表、曝光时间、采样权重、扫描方向 |
| 光源 | 数量、空间位置方向、发光面积、功率单位、SPD 或 RGB 近似、波形、相位组、平均/峰值策略 |
| 几何和材质 | 轨迹、材质参数、光谱数据引用、法线/粗糙度纹理、对象 ID |
| 相机 | 镜头/光圈、传感器尺寸、内外参、QE/CFA、满阱、噪声、增益、黑白电平、ISP |
| 主输出 | 频闪线性信号、稳定照明 GT、固定 ISP 版本；可选 RAW 与压缩版本 |
| 分解输出 | 每个独立光源/分量贡献、调制场或干净-输入差分、直接/间接光统计 |
| 可靠性 | 饱和/低信号/漏采掩码、参考时刻、曝光混合标记、几何标签的有效区域 |
| 近似级别 | 图像域 / 冻结几何 / 子帧 RGB / 光谱；光谱分辨率、时间采样密度、路径采样数 |

拆分必须在生成变体之前，按资产、场景布局、运动轨迹和灯具/驱动组进行。相同轨迹的相位变体或裁块不能跨 train/test。额外保留未见灯具、未见驱动、未见相机、未见材质和未见组合的 OOD 测试。

真实视频的开发集与最终测试集独立。素材用于校准后，就不应再作为“完全未见的真实泛化”证据。

## 12. 如何证明数据生成可信

1. **无调制恒等：**所有 q=1 时输入与 GT 一致至数值/采样误差。
2. **单灯解析对照：**静止平面正弦/PWM 与解析积分对比。
3. **完整周期：**静态周期信号完整周期曝光应消除相位差；半周期和非整周期作为反例。
4. **扫描控制：**τ=0 消除由逐行时间差形成的条带，但不要求帧间恒定。
5. **能量相加：**全灯线性渲染与逐灯贡献和一致；关闭非线性处理后检查。
6. **颜色对照：**固定 SPD、共同 q(t) 与分通道异相 q_j(t) 产生预期差别。
7. **材质对照：**灰卡、有色漫反射、金属、玻璃下测试不同灯的相对贡献。
8. **时间收敛：**加密子帧/开关事件积分后，误差持续减小；遮挡边缘单独报告。
9. **路径收敛：**提高光线采样，检查残余变化是不是渲染噪声或降噪闪烁。
10. **标签一致：**几何、光流、深度、分割的时间定义与图像一致，曝光混合边缘可标无效。
11. **真实测量比对：**固定灰卡/色卡和灯具，用光电测量或高速信号估计波形，比较静态及动态拍摄的行亮度图、相位推进、颜色与噪声。
12. **采样覆盖：**报告独立场景/灯具/轨迹数量、参数分布及有效退化强度；图像数量不是唯一多样性指标。

测量时保存仪器带宽、采样率、曝光/积分时长和误差；窄脉冲需要足够带宽。相机“防频闪”开关和 AE/AWB 会改变结果，应在标定中固定并记录。Pst/SVM 等人眼相关指标可以作灯具附加元数据，不能代替相机实际条带/漏采检查。

最终需要两种证据：**数值成像模型正确**，以及**模型能覆盖真实素材的主要现象**。第一种由解析/收敛测试支持，第二种必须有独立真实拍摄或测量支持。

索尼官方资料带来的增补：机械焦平面快门也可能是依次曝光；防闪烁择时与精细调节曝光时间是不同策略；记录文件和预览的闪烁表现可能不同。对应的参数和验证条件见 [索尼官方资料专题](04_sony_official_findings.md)。
